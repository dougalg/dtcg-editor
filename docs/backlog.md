Needs a formatter config (e.g. Prettier with `useTabs: true`) added, a one-time repo-wide reformat, and ideally a `pnpm format:check` CI gate alongside the existing build/lint checks so it doesn't drift back to spaces.

The other 5 workspace packages lint fine on ESLint 10 already. Verify upstream support (an `eslint-config-next`/`eslint-plugin-react` release compatible with ESLint 10) exists before attempting again.

Verify Next.js and `@typescript-eslint` both support TypeScript 7 before attempting again.
